## 使用建议

- 先看 [[01-项目介绍与简历]]，确定简历职责点与项目表述。
- 按 02 → 03 → 04 准备每个职责点的话术；技术追问查 [[05-项目衍生八股]]。
- 需要跑代码/压测时看 [[06-项目过程与代码索引]]；面试前看 [[07-面试问答与经验]]。
- 与 Redis 实战的对应关系：商户缓存 → [[Redis/实战篇/实战-商户查询缓存|实战-商户查询缓存]]；优惠券秒杀 → [[Redis/实战篇/实战-优惠券秒杀|实战-优惠券秒杀]] / [[Redis/实战篇/实战-秒杀优化|实战-秒杀优化]]；分布式锁 → [[Redis/实战篇/实战-分布式锁|实战-分布式锁]]；多级缓存 → [[Redis/高级篇/高级-多级缓存|高级-多级缓存]]。
