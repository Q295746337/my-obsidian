## AI 智能客服代码索引（集成版）

> 当前 AI 客服不在独立 `consultant` 项目里，而是集成在 `D:/Java/HMDP/HMDP`（包 `com.ncepuljxx.hmdp`，端口 8081）。完整说明见 [[08-AI智能客服实现]]。
> 以下按**完善后的实现**记录：批量查询、预约校验与返回值、服务端手机号绑定、归档 List + `LTRIM`、ThreadLocal 清理、API Key 外置等均已包含。

| 功能 | 文件 |
| --- | --- |
| AI 服务接口 | `src/main/java/com/ncepuljxx/hmdp/aiservice/ConsultantService.java` |
| 聊天/历史接口 | `src/main/java/com/ncepuljxx/hmdp/controller/ChatController.java` |
| AI 配置（记忆/RAG/意图路由） | `src/main/java/com/ncepuljxx/hmdp/config/CommonConfig.java` |
| Redis 会话记忆/归档 | `src/main/java/com/ncepuljxx/hmdp/utils/RedisChatMemoryStore.java` |
| 聊天历史服务 | `src/main/java/com/ncepuljxx/hmdp/service/impl/ChatHistoryServiceImpl.java` |
| 工具：商家/优惠券/预约 | `src/main/java/com/ncepuljxx/hmdp/aiservice/tools/` |
| 系统提示词 | `src/main/resources/system.txt` |
| 知识库文档 | `src/main/resources/content/hmdp.sql` |
| 前端页面 | `nginx-1.18.0/html/hmdp/chat.html` |
| Nginx 流式代理 | `nginx-1.18.0/conf/nginx.conf` |

**接口速查**

- `GET /chat?memoryId=&message=`：流式对话（Nginx 侧为 `/api/chat`）
- `POST /chat/session/new`：新建会话，返回 `user:{userId}:{sessionId}`
- `GET /chat/history/list`：当前用户历史会话列表
- `GET /chat/history/{memoryId}`：当前用户某个会话的完整消息

**Redis Key 速查**

| Key | 作用 |
| --- | --- |
| `memory:chat:{memoryId}` | AI 上下文窗口（最近 30 条） |
| `memory:archive:{memoryId}` | 完整对话归档（Redis List，`RPUSH` 追加，`LTRIM` 保留 2000 条） |
| `memory:index:{userId}` | 用户会话索引（ZSet，按更新时间倒序） |
| `rag:content:ingested` | 知识库导入完成标记，删除后重启可重建 |

**配置速查**

| 配置 | 作用 |
| --- | --- |
| `hmdp.memory.context-size` | 给模型的上下文窗口条数，默认 30 |
| `hmdp.memory.archive-max-messages` | 归档保留上限，默认 2000 |
| `DASHSCOPE_API_KEY` | 百炼 API Key 环境变量，不再写入 yml |
| `log-requests` / `log-responses` | 生产环境关闭，避免日志泄露对话 |
