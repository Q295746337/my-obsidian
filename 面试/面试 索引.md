# 面试 知识体系

本模块把 11 份面试 PPT 和 1 篇 SkyWalking 项目讲义整理成 12 篇面试笔记。每篇只保留“问题 → 答案要点 → 原理/示例 → 易错点”，完整技术讲解请跳转对应主笔记。

## 笔记列表

| 笔记 | 主题 | 一句话摘要 |
| --- | --- | --- |
| [[01-准备篇]] | 简历筛选、简历写法、练手项目、面试流程 | 从 HR 和部门负责人的筛选视角反推简历与项目准备 |
| [[02-Redis篇]] | 缓存三兄弟、双写一致、持久化、分布式锁、集群 | 用“缓存 → 一致性 → 锁 → 集群”串起 Redis 高频题 |
| [[03-MySQL篇]] | 慢查询、EXPLAIN、索引、事务与 MVCC、分库分表 | 从定位慢 SQL 到索引失效、MVCC 和分库分表一条线 |
| [[04-框架篇]] | Spring、SpringMVC、SpringBoot、MyBatis | 覆盖 Bean 生命周期、循环依赖、事务失效和自动配置 |
| [[05-微服务篇]] | 注册中心、负载均衡、熔断限流、分布式事务、幂等 | 按 Spring Cloud 组件和业务场景组织微服务问答 |
| [[05-微服务篇-项目链路追踪]] | SkyWalking、JavaAgent、链路追踪、告警 | 以一个项目的接入过程讲清 APM 与链路追踪 |
| [[06-消息中间件篇]] | RabbitMQ、Kafka 的可靠性、顺序、高可用 | 对照“消息不丢、不重、不乱、不堆”整理 MQ 面试题 |
| [[07-常见集合篇]] | 复杂度、ArrayList、LinkedList、HashMap | 从数据结构到 JDK 1.8 扩容与死循环问题 |
| [[08-并发编程篇]] | 线程、锁、AQS、线程池、ThreadLocal | 按“基础 → 原理 → 工具 → 场景”整理并发高频题 |
| [[09-JVM虚拟机篇]] | 内存结构、类加载、GC、调优排查 | 从 JVM 组成到 OOM/CPU 飙高排查的完整路径 |
| [[10-设计模式]] | 工厂、策略、责任链 | 用项目案例讲清三种最常被问的设计模式 |
| [[11-常见技术场景]] | SSO、RBAC、加密、ELK、生产排查 | 把“你项目怎么做的”类问题整理成可复用回答 |

## 建议复习顺序

1. [[01-准备篇]]：先确定简历和项目怎么讲。
2. [[07-常见集合篇]]、[[08-并发编程篇]]、[[09-JVM虚拟机篇]]：Java 基础三件套。
3. [[03-MySQL篇]]、[[02-Redis篇]]：数据层高频。
4. [[04-框架篇]]、[[05-微服务篇]]、[[06-消息中间件篇]]：框架与分布式。
5. [[10-设计模式]]、[[11-常见技术场景]]：项目表达与场景题。
6. [[05-微服务篇-项目链路追踪]]：作为监控与链路追踪的项目素材。

## 使用说明

- 每篇笔记的“面试速记”表可用于考前 10 分钟快速过题。
- 答案要点是面试口径，完整原理、源码和命令在主笔记中。
- 图片统一放在 `D:\Java\data\面试\`，使用 `file:///` 绝对路径引用。
- 原始 PPT 保留在 `面试/<专题>/PPT/`，未删除、未移动。
- 各专题下的 `在线讲义文稿.txt` 均为同一个飞书链接，不是正文，未转换。
