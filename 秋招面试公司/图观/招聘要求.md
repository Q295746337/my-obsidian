# 图观（天津）数字科技有限公司 招聘信息

## 一、全栈开发工程师
### 岗位职责
1. 负责公司AI产品、业务系统、管理后台、数据平台、工具平台等软件系统的全栈开发；
2. 熟练使用AI编程工具，通过代码生成、代码重构、单元测试、问题排查和文档编写完成技术落地；
3. 负责前端页面、后端服务、数据服务、API接口、项目功能测试等模块的开发与质量把控；
4. 配合算法团队完成AI模型、Agent、工具调用、SDK、接口等能力的集成与能力建设；
5. 建立并持续完善标准化、工程化开发规范，推动自动化测试、系统集成和产品化落地；
6. 参与代码架构优化、性能优化、故障排查、可维护性调优、异常处理、安全校验和上线回归；
7. 参与DevOps建设，推动CI/CD落地，持续优化研发效率，降低研发成本。

### 能力要求
1. 本科及以上学历，计算机、软件工程、人工智能、自动化等相关专业；
2. 熟悉至少一种主力开发语言，如Java、Python、JavaScript、Go等；
3. 熟练使用AI Agent工具辅助软件开发，具备较强的学习能力，能在AI辅助下完成高质量开发；
4. 熟练掌握MySQL、PostgreSQL、Redis、MongoDB中至少一种常见数据库；熟练使用Git、Docker、CI/CD等开发工具和流程；
5. 具备良好的代码质量意识，熟悉代码审查、单元测试、技术文档编写，具备独立解决问题的能力，可完成从需求学习到交付的完整闭环。

## 二、Java开发工程师
### 岗位职责
1. 参与公司产品后端服务的设计与开发，负责核心功能模块的编码实现与调试工作；
2. 负责微服务架构下的系统开发与优化，保障服务的高可用、高性能和可扩展性；
3. 参与需求分析、技术方案评审，输出合理的技术实现方案；
4. 配合前端工程师完成接口联调，配合测试、运维团队完成产品上线与运维；
5. 编写技术文档，维护和迭代现有系统，排查并解决线上问题。

### 任职要求
1. 本科及以上学历，计算机相关专业，有Java开发相关经验优先；
2. 精通Java语言基础，熟悉JVM原理、多线程、集合等核心知识；
3. 熟练使用Spring Boot、Spring Cloud等微服务框架，了解微服务架构设计；
4. 熟悉MySQL等关系型数据库，具备SQL优化能力，熟悉Redis、消息队列等常用中间件；
5. 熟练使用Git、Maven等开发工具，具备良好的编码规范和单元测试习惯；
6. 工作踏实，学习能力强，具备良好的沟通能力和团队协作能力。
