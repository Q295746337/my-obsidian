## 建议复习顺序（约 1.5 小时）

1. **先看 `01` 讲解稿**（30 分钟）：把「一句话定位 → 背景 → 两套场景 + 三端 + 网站 → 我的角色 → 三个亮点 → 获奖成果 → 坦诚不足」这条线讲顺。
2. **再看 `05` 速查卡**（20 分钟）：直接抄走里面的"优化版简历"，把逐句对照表过一遍，把队友的夸大点背清楚"为什么不能照抄"。
3. **精读 `03` + `04` 问答**（40 分钟）：每题先自己答再看答案；标"必问"的要能 30~60 秒口头复述。
4. **细节查 `02`**（10 分钟）：记不清某个数字/口径时翻。
5. **考前 5 分钟**：只看 `05` 的一页速查卡 + `01` 的电梯版。

## 三条不能踩的红线（背熟）

1. **诚实高于包装**：3 人、200 元经费的大创项目，不说"自研引擎 / 云原生 / 千万级产品"这类词。
2. **AI 措辞守住文件口径**：文件叫 **"AI 向导 / 智能村民"**，不叫"数字人"；是 **"村民身份提示词（prompt）"**，不是"垂类身份预训练/微调"；延迟 <1.5s、准确率 98% 是**项目自述指标，不是第三方压测**。
3. **获奖与立项口径（已确认）= 可直接讲、别加细节**：国家级大创、结项良好、计算机设计大赛全国三等奖/省赛一等奖、软著申请中——你确认这些都是真实的，那就正常讲，但要**说完整、说准确**："这是国家级大创项目，结项良好，拿了计算机设计大赛全国三等奖、省赛一等奖，软著申请中。" 手边备好证书/截图备查即可。

3. **备好获奖证书 / 参赛截图 / 结题证明**（全国三等奖、省赛一等奖、"国家级"级别、"良好"、"软著申请中"都要有据，别只靠嘴说）。

## 关键词速记

- **一句话定位**：UE5 引擎 + 骆驼湾村原型的红色乡村数字孪生平台 = 两套高精度场景 + PC/Android/VR 三端 + 线上网站。
