## 二、6 个技术词：在这个项目里到底"用在哪、怎么用"

> 每个词给你三样东西：**用在哪（能答"你用了它吗？用在哪？"）→ 怎么用（一句原理）→ 糊弄话术（可直接背）→ 被追问的兜底（快顶不住时）。**
> 原则："糊弄"不是撒谎，是**把"这个项目里它在哪"讲清楚 + 承认"底层不深" + 把话题引回你的主攻点（UE 交互 / Web）**。

### 1. Pixel Streaming（像素流送）+ 云渲染

- **用在哪**：网站的"虚拟展馆"入口——用户在网页上免下载、免本地高性能显卡，直接在线进入 3D 展馆。
- **怎么用**：服务器带 GPU 跑 UE 渲染，把画面编码成视频流推到浏览器；浏览器把键鼠/触屏输入回传服务器。云渲染就是"渲染放服务器"这个更大的概念，Pixel Streaming 是它的落地。
- **糊弄话术**：
  > "我们用 UE 的 Pixel Streaming 把展馆做成网页免安装在线体验——原理是服务器渲染、视频流推到浏览器、输入再回传。做到演示/单用户级别，带宽和并发调优是更进阶的事，我们没深做。"
- **兜底**：被问 WebRTC/延迟/并发的细节时——> "这块我主要负责集成和调用，原理清楚，具体到 WebRTC 的参数调优和并发我不是最熟的。"

### 2. WebSocket

- **用在哪**：网页端与 UE/服务器之间的实时通信（网页操作指令、状态同步）。
- **怎么用**：基于 TCP 的全双工长连接，HTTP 握手升级后双向收发 JSON 消息。
- **糊弄话术**：
  > "网页和服务器之间用 WebSocket 做双向消息，把网页的操作传进去、把状态推回来。我们就是基础的长连接 + JSON 收发，没做房间、集群、心跳重连那些高级的。"
- **兜底**：被问"为什么不用轮询/SSE"——> "轮询开销大、不够实时；WebSocket 双向长连接正好合适。更深对比我可以再补，但我们场景用它就够了。"

### 3. Niagara

- **用在哪**：天气系统里的**雨、水雾**粒子效果（风雨天/水雾天就是这做的）。
- **怎么用**：UE5 的新粒子系统，用现成粒子模板调数量、速度、材质，没自写 HLSL。
- **糊弄话术**：
  > "天气里的雨和水雾我用 Niagara 的粒子模板搭的，调了参数做出氛围感；没深入去自定义粒子逻辑。"
- **兜底**：被问"Niagara vs Cascade"——> "Niagara 模块化更强、GPU 粒子更好，是 UE5 主流的粒子方案，我们直接用它的能力。"

### 4. MPC（Material Parameter Collection，材质参数集）

- **用在哪**：**切换天气 / 昼夜**时，统一调一批材质的亮度、色调、潮湿感（下雨整体偏冷、夜间整体变暗）。
- **怎么用**：全局材质参数表，材质里读同一组参数，改一处全场景联动。
- **糊弄话术**：
  > "切天气或白天黑夜时，我用 MPC 做全局氛围统一切换——改一处参数，让一批材质跟着一起变，不用逐个材质改。"
- **兜底**：被问"为什么用它"——> "全局状态要同时影响一大批材质时用参数集最高效，改一处全联动。"

### 5. 3ds Max

- **用在哪**：房屋、家具、农具等**静态模型的建模**（这条是队友主力，你参与/了解）。
- **怎么用**：建多边形模型、展 UV、贴图，导出 FBX 进 UE。
- **糊弄话术**：
  > "静态模型（房屋、家具）是队友在 3ds Max 里建模、展 UV、贴图，导 FBX 进 UE；我这边主要在引擎里接材质、光照和蓝图交互。"
- **兜底**：被问"你怎么建模的"——> 诚实说"建模主要是队友，我更多在引擎侧"（和你的定位一致，不露怯）。

### 6. 云渲染（单独被问到的话）

- **用在哪**：和 Pixel Streaming 是同一个意思——"服务器端渲染 + 网页流式访问"。
- **糊弄话术**：
  > "我们说的云渲染是轻量的——一台服务器跑 UE、把画面推给网页，让用户免安装。不是上了云平台的弹性渲染集群 / 容器化那套。"

## 三、通用"糊弄"心法（面试全程用）

1. **永远按"用在哪 + 做了什么 + 引回主攻点"三段式答**：先定位它在项目里的位置，一句原理，然后"这块我更熟的是 XX（UE 交互 / Web）"把话题带回来。
2. **诚实挡深度**：被追问底层，就说 "这块我主要负责集成和调用，原理清楚，底层细节不是我最熟的"—— 这比硬编更安全。
3. **主攻点背熟 2 个能讲 3 层的东西**：UE 交互（挑自动门/答题机一个讲碰撞触发→按键→状态切换→结果反馈）+ Web（主页/留言审核/下载统计/内容管理讲出前后端闭环）。这两块是你最该下功夫的，其它 6 个词"能糊弄过去"就够了。
4. **别主动报自己不熟的词**：面试官不问，你不必主动提 Niagara/MPC；简历里有，被问到了再按上面的糊弄话术接。
